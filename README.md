# Knights Quest ♞

A simple 2D game built with Python and Pygame, inspired by the *Beginner's Step-by-Step Coding Course* book. The player controls a knight navigating a board, collecting keys, and avoiding guards to progress through each level.

## 🎮 Gameplay

The objective is to collect all the keys scattered across the board while avoiding the guards patrolling the area.

- **Move the knight:** Navigate around the board to explore the level and collect keys.
- **Collect keys:** Find all the keys to unlock the exit.
- **Reach the door:** Once all keys have been collected, the exit door appears.
- **Complete the level:** Enter the door to win the level and advance to the next one.
- **Avoid the guards:** If a guard catches the knight, it's game over!

## 🕹️ Controls

| Key | Action |
| --- | --- |
| Arrow keys | Move the knight around the board |
| Enter | Start or progress through the game, where applicable |

## 🛠️ Technologies

- **Python** — Core game logic and programming.
- **Pygame** — Game window, graphics, player movement, and gameplay mechanics.

### Prerequisites

## 📚 Inspiration

This project was created as a learning exercise based on the book [*Beginner's Step-by-Step Coding Course*](https://www.booktopia.com.au/beginner-s-step-by-step-coding-course-dk/book/9780241358733.html), published by DK.

The project provided an opportunity to practise Python programming concepts, including game logic, player movement, collision detection, and level progression, while building an interactive game.

## 🎯 Project Goals

- Practise Python programming fundamentals.
- Learn to use Pygame to build a 2D game.
- Implement player movement and collision detection.
- Work with game states, including winning and game-over conditions.
- Develop level progression and interactive gameplay mechanics.
